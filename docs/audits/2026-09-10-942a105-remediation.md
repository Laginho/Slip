# Remediation of audit 2026-09-10-942a105

The original audit remains unchanged. This record covers the corrective work for every
named finding. Delivered by PR #26, merged as `87702c6`.

- `body` in the `index.html` reset sets `overflow-wrap: anywhere`, so an unbreakable
  token wraps inside its Card. Inherited, so one declaration reaches the phone bubble,
  the wall square and the Archive row at once; `anywhere` rather than `break-word` so a
  long token cannot widen a grid track or a flex item before it breaks. Measured at both
  profiles: 390px text ends inside the Card box, 1200px Cards `16→292` and `308→585`
  with nothing clipped, `document.scrollWidth === innerWidth` on both.
- The viewport no longer carries `maximum-scale=1.0`, restoring pinch-zoom on the Android
  Chrome profile PRODUCT names as primary. It failed WCAG 1.4.4, contradicted the 1a
  spec's justification for having no density setting, and bought nothing — iOS Safari has
  ignored it since v10.
- DESIGN describes the shipped Archive above the Open list, the right-aligned toast, the
  16px archive row against the 14px empty note, and the real input font sizes (18px
  capture textarea, 14px day field) in place of the blanket 16px claim.
- The send button's block condition is stated as it behaves: blank text, or the day
  `0`/`00` — the only values the field accepts that resolve to no date, since
  `inferDeadline` scans a year ahead and every day 1–31 lands in some month.
- The Card editor's `aria-label` is `"tarefa"`, the only English label left in an
  all-Portuguese UI under `<html lang="pt-BR">`; its test selectors were renamed with it.
- The never-called `open_url` and `set_var` were deleted from `scripts/setup-publish.sh`,
  and the stray 297-line `setup-ticket-07.sh` under a ticket closed on 2026-08-31 went
  with them.
- `tracker/` was retired rather than migrated to, taking its `.gitignore` rules with it.
  `docs/agents/issue-tracker.md` is the live convention; the two files there were
  untracked artifacts of a workflow superseded on 2026-09-05. Three consecutive audits
  had recorded that migration as unactioned.
- `.claude/launch.json` declares the dev server so browser verification stops being
  tribal knowledge.

Two guards are pinned as file-content assertions in `src/identity.test.ts`, because jsdom
never loads the `index.html` stylesheet and pinch-zoom cannot be asserted at all: the
`overflow-wrap` declaration, and the absence of `maximum-scale`/`user-scalable` anywhere
in the file.

Left open, on the audit's own advice: the duplicated test helpers move to
`src/testing.tsx` when a third consumer needs them. Unactioned and unticketed: the audit's
Process note that CI runs no job on pull requests — `AGENTS.md` makes the merge the
human's call by design.

Gates: 13 files / 307 tests, `npx tsc -b`, `npm run lint`, `npm run build`,
`npm audit --audit-level=high --omit=dev` with 0 vulnerabilities.
