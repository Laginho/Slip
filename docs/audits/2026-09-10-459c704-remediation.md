named finding.

  public form-seam regression covers both values and confirms that no Task is stored.

  clean detached `standup-*` worktrees were removed and `.claude/worktrees/` is ignored
  by the repository rather than only by machine-local Git configuration.

  list. Stale padding, typography, test-count, and issue-number documentation was fixed.

  shares one harness, builds into a fresh temporary output directory, and does not inspect

- Card reuses the guarded `fine` media-query value in its tap timer.
- Shared App-test helpers moved to `src/testing.tsx`; App and Card test suites were split
  at existing `describe` boundaries so no test file exceeds 800 lines.
- `package.json` and its lockfile declare Node 22, and deployment CI now runs a high-level
  dependency audit before the product gates.
